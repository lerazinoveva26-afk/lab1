# Вариант 2. Консольная программа для перевода единиц измерения
## 1. Назначение проекта
Данная программа представляет собой консольное приложение на языке Python, предназначенное для быстрого перевода физических величин из одной системы измерения в другую. Программа помогает пользователю конвертировать температуру, длину, массу, не прибегая к ручным расчетам или поиску формул в интернете.
## 2. Задачи, которые решает программа
Программа решает следующие задачи:
- Перевод температуры из градусов Цельсия в градусы Фаренгейта и обратно.
- Перевод расстояния из километров в мили и обратно.
- Перевод массы из килограммов в фунты и обратно.
- Перевод длины из метров в футы и обратно.
- Обеспечение корректной обработки ввода пользователя (защита от ввода букв вместо чисел и от неверных номеров меню).
## 3. Инструкция по запуску
Для запуска программы необходим установленный интерпретатор Python. Сохраните код программы в файл с расширением `.py`. Откройте командную строку в папке, где находится файл. Выполните команду:
```
python название_файла.py
```
## 4. Как пользоваться программой
После запуска на экране появится главное меню со списком доступных конвертеров (от 1 до 4) и пунктом выхода (0). Введите цифру, соответствующую нужному разделу, и нажмите Enter. Откроется подменю, в котором нужно выбрать направление перевода. Введите числовое значение величины, которую нужно перевести. Программа выведет результат перевода на экран. После завершения расчетов программа снова вернется в главное меню. Для выхода из программы введите 0.
## 5. Пример работы программы 
Ввод:
```
Выберите конвертер:
1. Градус Цельсия <-> Градус Фаренгейта
2. Километры <-> Мили
3. Килограммы <-> Фунты
4. Метры <-> Футы
0. Выход

Ваш выбор: 1

Выберите направление:
1. Градус Цельсия -> Градус Фаренгейта
2. Градус Фаренгейта -> Градус Цельсия

Ваш выбор: 1
Введите температуру: 36
```
Вывод:
```
36.0 C = 96.8 F
```
